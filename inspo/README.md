# Portfolio-Inspiration – Daniel Lenski

Screenshots (1440×900, captured 2026-09-24) of sites picked to match the profile from CV + LinkedIn export:
Wirtschaftsingenieur (M.Sc.), BI/Power BI/Jedox consulting (Atvisio), Lean Six Sigma, target roles in
operations/lean/process consulting, thesis on additive manufacturing + LCA in aviation (RWTH), DLR
heliostat cost paper, 3D printing, football referee, AI automation with Claude.

Filter applied against CLAUDE.md: the current site is a light-only "BI dashboard" reading of the CV,
so the picks focus on **light themes, data-viz done tastefully, and engineering case studies**.
